HW 2: Unity Roll-a-Ball

CS 480 · Unity Gameplay Assignment

Gameplay Demo

Personal Modification

For this assignment, I followed the Unity Roll-a-Ball tutorial and then made my own modification. I added the ability to jump as the player by pressing the space key.

What I Learned

I found that creating components and materials was not difficult. The difficult part was putting everything together. Ensuring all the elements work together as intended and accounting for all the possibilities is the most tedious part. For example, detecting collisions as the player in order to ensure it is grounded and allow the jump action.

GameObjects in unity are entities which can use components and scripts. When a component or script is added to a GameObject, something about it's behavior changes. Components define certain properties of the GameObject, while scripts are fully personalizable and define both behavior and custom properties. Objects can also be related through hierarchy or references to other objects. For example, the player object has a reference to the enemy object.

Connection to the XR Documentary

The skills I learned in this assignment will be useful for creating my interactive XR documentary because I will now be able to create interactive scenes rather than just static ones. I will be able to take in player input, which will make the experience more engaging. I will also be able to create triggers for certain events and create dynamic objects to liven the scenes. In a similar way to video games, an interactive documentary will allow the users to engage with the characters and their stories. It will encourage empathy and allow users to experience the story in a more personal way.
